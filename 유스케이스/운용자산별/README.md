# 운용자산별 유스케이스

Reflexivity의 리서치 및 워크플로 예시를 주요 운용자산과 시장 기준으로 살펴볼 수 있습니다.

하나의 유스케이스가 여러 자산군이나 페르소나에 동시에 관련될 수 있습니다. 동일한 본문을 여러 폴더에 복제하지 않고, 하나의 문서를 여러 탐색 경로에서 링크합니다.

## 자산군

- [FX](FX/README.md) — 영문 canonical 기준 3개 페이지 동기화 완료
- [채권](채권/README.md) — 첫 3개 페이지 동기화 완료

나머지 자산군과 채권의 추가 페이지도 영문 canonical 문서를 기준으로 검증된 묶음부터 순차 동기화합니다.
